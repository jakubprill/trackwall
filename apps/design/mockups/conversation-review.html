The conversation view as the place to review the agent's changes

For a frontend developer the work is in the diffs. A wide panel puts the files the turn changed beside the conversation, the agent's plan sits above both, and a line of a diff takes a review comment, opens in VS Code or goes into the message as a quote. A narrow panel (a grid tile, the supervisor) keeps each change as a card in the conversation.

Plan

The agent's plan as ACP sends it (to be confirmed with a contract test on Copilot CLI): done, current and waiting steps. Folded to the current step in a narrow panel.

Files beside the conversation

The files the selected turn changed, from the diffs of its tool calls; a file card in the conversation selects it. "Whole file" switches to the task's Changes for the full worktree diff.

Actions on a line

Comment: a review comment, the same as in Changes, delivered when the turn ends. Open in VS Code: the worktree file at that line. Ask about this: the line goes into the message box as a quote.
