Every task in the grid with one click

The grid in the Auto layout already shows the whole list (up to 9 tiles a page). The trouble is that it shows everything at once: ended tasks without a session, proposals, sessions in repos. So instead of a separate “open all” button, a Show filter on the layout bar says what goes into the grid.

Click a dimmed row in the list: the filter goes back to All. In “Waiting”, click a tile to “answer” it: it stays dimmed until the filter changes.

How it works

  1. All is today's behaviour, unchanged.
  2. Running is everything with a live Copilot session: tasks and sessions in repos. This is “open every running task”. Ended tasks without a session and proposals drop out.
  3. Waiting is only what waits for you (an approval, a question, a proposal). The number on the chip says how many.
  4. Repo ▾ narrows to one repo, together with the chosen state filter (for example Running in orders-api).
  5. Choosing a filter switches to Auto if the layout was 1, so it really is one click. The filter is remembered with the layout.
  6. The list on the left stays full, and entries outside the filter are dimmed. Numbers and Alt+digit still point at the position in the list, and tiles show the same number.

Details

  • Selecting an entry outside the filter (a click or Alt+digit) resets the filter to All, so the selected entry is always visible.
  • In “Waiting” a tile that stopped waiting does not vanish at once; it dims until the filter changes. Otherwise terminals would jump and resize while you type.
  • An empty filter shows a message (“Nothing is waiting for you”) instead of an empty grid.
  • In code: a pure function in lib/session-grid.ts with tests, chips on the layout bar, a description on the Sessions page of the docs. No daemon change.

Open question

Is the filter enough, or a separate “Open all tasks” button that shows only agent tasks (no sessions in repos)? Recommended: the filter, because “Running” does the same, and “Waiting” and the repo come almost for free. Not built yet.
