Features // Sessions · Ctrl+3since 0.2.0

Copilot CLI sessions

Run several Copilot CLI agents at once, each in its own repo, and see at a glance which one is waiting for you.

What it does

Each session runs in a terminal owned by the daemon, so it keeps working after you close the window. Trackwall reads the session state from Copilot CLI hooks: working, waiting for you, asking for approval or idle. Every session has the Trackwall MCP server connected, so the agent can read repo cards, logs and the connection graph.

Start a session

  1. Open Sessions with Ctrl+3 (⌘+3 on macOS).
  2. Choose a repo from the projects folder.
  3. Type into the terminal as in any Copilot CLI session.
NeedsCopilot CLI on PATH (copilot) and the daemon running under Bun, as in the release build. Under Node there are no sessions.

Shortcuts

KeysWhat happens
Alt+1…9Selects the session at that position in the list.
Alt+JJumps to the next session waiting for you, from any view.
Win+Alt+JBrings Trackwall to the front from any app and opens that session.
