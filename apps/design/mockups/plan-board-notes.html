Board and notes

A personal layer under the issue tracker, not a second tracker: a work tree with an idea inbox that saves an idea in two seconds, a board of items, and a knowledge base per repo, with MCP tools for agents. The tab is called Board with items (BoardItem), because a task in Trackwall is already an agent's task in a worktree. Built as the Plan view (ADR-133).

Views

The mockups show the layout, not the final look. Texts in English, as in the product.
