Notes

  • The count is of repos, not of points. “2 of 6 ready” counts the repos with no gap that blocks or weakens agents, and the bar splits the rest into blocked and with gaps; a percentage of checks passed would hide that one missing test task stops Verify.
  • A, by gap, puts one fix under each gap for every repo it touches, the way Version drift does; convention tasks fix every repo in one click. B, by repo, reads like a to-do list but repeats the same fix in many rows.
  • Every fix already exists or starts an agent task with a prompt to read first; nothing starts on its own.
  • Checkout and an incomplete card are shown but not counted: they change every hour and do not stop an agent.
  • Later: “proven”, whether the last test run passed, to tell a configured repo from a working one.
