Trackwall · Sessions view · mockup · 2026-10-29

A task tile among six sessions

The tile header stays on one line. What needs your reaction gets its own yellow chip with a name in it, instead of a bare count of warnings. Other actions and information go into the ⋯ menu, so they take no room. Cards over the terminal are opaque.

Card background Click the chips, ⋯ and the buttons in the tiles. The grid has the size of a 1920 px screen with the list next to it.

What changes

  1. A “Trust mise” chip in the header stays lit until the mise config is trusted. It does not vanish when the banner is closed. A click opens a small card: the changed files (foldable), “Trust this config” and “Open in VS Code”. No other task details.
  2. Other warnings (shared files, files not copied) stay under the ⚠ badge with a count, as before.
  3. The ⋯ menu: branch, port, model and age on top. Below: VS Code, Verify, Changes (opens the task alone, on its changes), Details, Stop or Resume.
  4. Opaque cards. A card used the panel background, which in a window with Mica/Acrylic is 55% opaque, so the terminal showed through the text. Cards over the terminal get a full background.
  5. The Verify result shows as a small chip (✓ or ✗), because it is short and important.

When the tile is narrow

  • First the task description hides (it stays in the tooltip), then the state text becomes a dot in the state colour.
  • The mise chip and ⚠ never hide. In a very narrow tile the chip shortens to “mise”.
  • Everything in the menu also has a shortcut in the single task view, so nothing is lost.

In code

  • UI only. The new chip uses the existing mise warning, and the trust card the existing TaskMiseConfig.
  • Unit tests for what goes into the header, and the grid E2E test where it touches it. A description on the Sessions page of the docs.

Decided

Always visible in the header: only “Trust mise”, ⚠ and the Verify result; VS Code is the first item of the menu. Built (TaskTileNotices, lib/task-notices.ts).
