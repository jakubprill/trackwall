What got in the way

Diagnosis of the scene in 0.4.1

A clean repo has no name.A label shows only with changes. When everything is clean, you see six anonymous boxes and cannot tell which is which.
Dark on grey.The solids have the card colour (almost black) under “studio” light on a transparent background. The contrast is low, and a clean repo's state is the --secondary colour, almost the background.
The solids do not glow.The shape of the kind (terminal, gateway, rack, box) is lost from afar. The inspiration works because the objects are light on a dark background, not solids in light.
The label says nothing.It is only the name or the state in a grey frame. The number of changes, the commits to pull and a running task show only in the card on hover.

Recommendation

A · Holo, with two changes from the inspiration

  • No percentages. The inspiration shows “65%”, but there is no honest percentage for a repo. We show the numbers the model already has: changes, commits to pull, a task. The only real fraction is working sessions out of all, and that draws the arc in the core.
  • No bloom. A post-processing glow takes several full-screen passes. On an integrated Intel GPU at 125–150% scaling on Windows that drops frames at once. Here every glow is a sprite with a gradient texture and additive blending: no extra passes.
  • The name always, the value only when needed. A clean repo gets a quiet label with only its name. A repo with changes, commits to pull or a task gets a full callout. A session gets a label only when it waits for you or has an error, as before. The “Only important” switch on the scene shows the old mode for comparison.
  • Performance guards: DPR capped at 1.5; shared geometries and textures; without motion (reduced motion or a hidden window) the scene draws only after a camera move; labels laid out in one SVG layer.

C fits later as an automatic power-saving mode, should A not stay smooth on a slower machine. The frame counter in the lower left corner of the scene shows how it runs on your hardware.

What would change in the code

Scope of variant A

  • packages/scene/src/models/: new solids of four kinds, a base with a state arc (a canvas texture, one per state), a new core with rings, a session drone with a glow. The HomeScene contract unchanged.
  • home-labels.ts: a repo always has a label, and the scene also passes the quiet or full variant to createLabel.
  • A layer of leader lines in the UI (HomeCanvas): Pawn Labels gives only the label's position, so the lines and the spreading are done in one SVG. Possibly a Pawn request (“a label with a leader line”).
  • Colours still from the UI tokens. A clean repo moves from --secondary to a dimmed --primary, so it shows against the background.
  • Tests: the label spreading and the choice of label variant as unit tests in packages/scene/test; the existing Home E2E test keeps passing. A new ADR.
