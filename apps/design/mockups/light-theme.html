Trackwall // proposal // theme

Light and system theme

Trackwall has one dark theme (ADR-16). This proposal adds a light one and a third choice, System, which follows Windows or macOS and switches live when the system does. Every colour of the app already comes from the tokens of index.css, so a theme is a second set of values for the same tokens. The accent and the state colours cannot be copied: on a light surface today's cyan has a contrast of 1.7:1, so they are darkened until every pair passes WCAG AA (the table at the end).

The switch in Settings › App

Three choices; Dark stays the default, so an update does not turn the app light on a light work desktop. The desktop shell keeps the choice, so a window opens in its theme without a flash, and gives every window (main, extra windows, the tray panel) the same theme: the title bar, Mica and vibrancy follow it.

ThemeDark, light, or the same as Windows or macOS.

Try it: the switch repaints this setting. System follows the colour scheme of the device you read this on.

Terminal and 3D scene in light
  • Variant A, recommended: the terminal and Home's scene stay dark inside the light window, like the terminal in many editors. The scene's holograms glow by adding light, and added light vanishes on a light background (see the 3D strip in variant B); Copilot CLI may also paint parts of its screen in its own colours meant for a dark background. A keeps both readable on day one.
  • Variant B, later: a light terminal with its own 16 ANSI colours, once a test against the real Copilot CLI shows its whole screen reads on light; and, only if wanted, a light scene with solid colours instead of glow.
  • Graph, Flow, the Plan board, Settings and the new charts use tokens only, so they need no work of their own beyond checking them on screenshots in both themes.

How it would be built

  • The light values go into index.css under a theme attribute on <html>, next to today's; a test makes every colour token have both, and computes this contrast table in the unit tests.
  • The shell sets the theme of every window (light, dark, or none to follow the system), so WebView2 and WebKit report the matching prefers-color-scheme, and Mica, Acrylic's tint and vibrancy follow it.
  • The terminal and the scene read the tokens once today; they read them again when the theme changes. Mermaid diagrams take the matching theme.
  • Proof in the PR: the contrast test, an end-to-end test that Light repaints and System follows an emulated system scheme live, and screenshots of every view in both themes.
