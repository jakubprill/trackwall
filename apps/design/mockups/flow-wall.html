Flow: the work of every group on one wall

A view for a second monitor that answers three questions without a click: what are the agents doing, what waits for me, and what has been standing too long. It adds no new kind of group: a project of Plan already is a batch or an epic, a change across repos already groups its parts, and the supervisor's tasks already form a group on the Sessions list. Flow only lays them all side by side.

What it shows

  • One row per group: each project of Plan with tasks, each change across repos, the supervisor's tasks, then tasks of no group. A row shows how far the group is.
  • One column per state: Working, Waits for you (a question or an approval), In review, Stuck (an error, a failed pipeline or Verify, no activity for a long time), Done today.
  • Time in the state on every card. A card past its limit turns red, so a stuck agent shows from across the room.
  • A click opens the task in the window that shows Sessions, as the tray does, so the wall keeps its view.

What it does not do

  • No editing. Columns are states the daemon already knows; moving work stays in Plan and Sessions.
  • No new data. It is computed in the UI from the session list, the tasks, the board and the task outcomes it already holds, like the progress of a project in Plan.
  • No order of its own for In review. That queue will follow the risk of the change's evidence once it exists.
  • No terminals. The session grid stays the place to watch an agent type.
