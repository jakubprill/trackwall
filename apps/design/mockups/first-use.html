Sessions · first start and every start

First use: start where the work starts

Today Trackwall opens on Home every time, also on the very first start, when Home has nothing to show and only sends the user on to "Get started" in Settings, from where "Start a session" leads on to Sessions. Next to it the supervisor panel takes a third of the window with a highlighted "Start my day", which cannot work before a projects folder is set. The proposal: open on Sessions, show the steps still missing right there, and keep the supervisor folded until the user starts it. Home stays one click away.

Variant A · the view bar

The view Trackwall opens on comes first

Sessions moves to the top and takes Ctrl+1; Home moves to the end. The macOS menu bar follows the same order. Opening a view in a new window (Ctrl+Shift + its digit) works as before, so Home can still live on a second monitor. The cost: four shortcuts change once, for users who learned them.

Variant A · in a dev container · not built

Work that is only in the container moves to Repos, with a count on its icon

"Only in this container" is on Home alone today, so every start shows it. Once Trackwall opens on Sessions, the repos whose commits, stashes or changes live only in the Docker volume head the repo list, and the Repos icon carries their number in the warning colour, from every view.

Built instead (ADR-287): Home keeps the section, and Home's icon carries the number of the container's warnings in every view, among them unpushed work whose last backup is old. In a container some work is nearly always unpushed, so a count of those repos would never go away. Since ADR-294 the number is on the Settings icon, which opens Diagnostics.

Variant B · the smallest step

Open on "Get started" until it is ready, then on Sessions

The main window opens on Settings › Get started while a needed step is open or no session ever started, and on Sessions after that. It skips the Home hop and changes no view, but keeps three screens' worth of setup in two (Get started, then Sessions), four clicks, and the pinned supervisor panel with its Start my day.

Variant C · not proposed then · built later (ADR-294)

Home off until turned on in Settings

Home leaves the view bar and comes back with one switch on the Home scene row of Settings › App. It takes one icon off the bar, but adds a setting, hides the view the README opens with, and a new user would never find it. Once Trackwall no longer opens on Home, Home costs nothing until it is clicked.

Built later (ADR-294), once "Repos" opened on "All repos" (ADR-293) and Home had little of its own left: "View bar", Shown or Hidden, on the Home row of Settings › App; the container's count on the Settings icon; "Close all" at the top of the Sessions list. Ctrl+6 and the command palette still open Home.
