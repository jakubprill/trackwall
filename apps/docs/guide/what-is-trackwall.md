# What is Trackwall

A desktop app for working across many git repositories and many CLI coding agents at once.

Point Trackwall at your projects folder, and it keeps every repo there in view: what each one is built from, how the repos call each other, and which of them have changes waiting. Next to them it runs your Copilot CLI sessions, tells you which agent is waiting for you, and gives the agents the same picture of your repos through its MCP server.

Trackwall keeps working in the background when you close its window: sessions and running services go on, and the tray tells you when an agent needs you.

It is at a very early stage: expect missing features, rough edges and breaking changes between versions.
