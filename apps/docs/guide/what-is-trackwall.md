# What is Trackwall

Trackwall is a desktop app for working across many git repositories and many CLI coding agents at once. It is at a very early stage: expect missing features, rough edges and breaking changes between versions.

It keeps the repos of one projects folder in view, reads what they are made of and how they call each other, and runs Copilot CLI sessions next to them. A daemon does the work and keeps running when the window is closed; the window, the tray and the agents talk to it.

These pages describe what Trackwall does today, one feature per page. The interface is in English, so the names of views and buttons in quotation marks are as in the app.

- [Home dashboard](/features/home): the whole environment in one 3D frame and the "Needs you" queue.
- [Repos](/features/repos), [mise tasks](/features/mise-tasks), [Services](/features/services), [Repo card and tags](/features/repo-card), [Connection graph](/features/graph) and [Batch command](/features/batch-command): working with the repos.
- [Copilot CLI sessions](/features/sessions), [Agent tasks](/features/tasks) and [Main session and task proposals](/features/main-session): working with agents.
- [Navigation and windows](/features/navigation-and-windows), [trackwall:// links](/features/links) and the [MCP server](/features/mcp): what works everywhere.
