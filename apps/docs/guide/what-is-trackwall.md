# What is Trackwall

Trackwall is a desktop app for working across many git repositories and many CLI coding agents at once. It is at a very early stage: expect missing features, rough edges and breaking changes between versions.

It keeps the repos of one projects folder in view, reads what they are made of and how they call each other, and runs Copilot CLI sessions next to them. A daemon does the work and keeps running when the window is closed; the window, the tray and the agents talk to it.

These pages describe what Trackwall does today, one feature per page; the sidebar lists them all. The interface is in English, so the names of views and buttons in quotation marks are as in the app.
