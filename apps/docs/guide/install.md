# Install

Trackwall runs on Windows (x64) and macOS (Apple Silicon). Builds are zip archives on the [Releases](https://github.com/jakubprill/trackwall/releases) page, without an installer.

The builds are not signed yet, so Windows SmartScreen and macOS Gatekeeper block the first start. The [installation notes](https://github.com/jakubprill/trackwall/blob/main/docs/release.md#installing-on-a-new-computer) show how to download, check and start Trackwall on each system.

After the first start, set the projects folder in "Settings" and [connect Copilot CLI](/guide/connect-copilot-cli).
