Trackwall 0.5.2 makes sessions start and work faster on machines where an antivirus scans every program start, keeps local mise tasks safe outside the repo, and finds endpoints described in OpenAPI specs.

## Faster sessions

- **No program per agent step.** Trackwall used to start a small program at every step of a session's agent to follow its state, and an antivirus could hold each one up for a second or two. Sessions now report to Trackwall directly, so the agent no longer waits for it. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions).
- **Trackwall's tools without a bridge.** A session reaches Trackwall's MCP tools directly instead of through a helper program started for each session. Behind a proxy, Trackwall adds `127.0.0.1` to `NO_PROXY` for its sessions so the tools stay reachable; programs the agent runs see that value too.
- **Copilot CLI's own package.** If your antivirus skips only your projects folder, you can move Copilot CLI's package there with `COPILOT_PKG_CACHE_HOME`; [Sessions](https://jakubprill.github.io/trackwall/features/sessions) shows how.

## What's new

- **Local config backup.** Where a team does not want mise configuration in its repo, keep your tasks in `mise.local.toml`. Trackwall backs it up (and `.worktreeinclude`) into `.trackwall-local` in your projects folder a few seconds after it changes, keeps every version, pushes the backup when you give it a remote, and offers "Restore from the store" in a fresh clone and "Ignore locally" so the file never reaches a commit. See [Local config backup](https://jakubprill.github.io/trackwall/features/local-config).
- **Endpoints from OpenAPI specs.** `find_endpoint` and the graph now also read endpoints from OpenAPI specs in a repo, not only from code. `find_endpoint` takes a path the way you have it: with or without a context path or gateway prefix, a whole URL, `GET /api/orders/42`, or a few words such as "cancel order", closest matches first. See [Graph](https://jakubprill.github.io/trackwall/features/graph).
- **Remove a repo from the supervisor.** Ask the supervisor to remove a repo you no longer need and it proposes the removal; "Remove repo" moves the folder into `.trackwall-removed` in your projects folder, so you can move it back. Trackwall refuses while a session, a task or a service still uses the repo. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).

## Moving from 0.5.1

Click "Update and restart" when Trackwall offers 0.5.2, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays. Sessions still running from 0.5.1 end with the restart; new sessions use the faster way to reach Trackwall.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
