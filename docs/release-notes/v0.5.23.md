Trackwall 0.5.23 makes Plan a place to work in, with a sorted inbox, project progress, a board and a reviewable knowledge list, moves board items along with their tasks, gives usage its own wide Settings category, and can keep the screen on while agents work.

## What's new

- **A sorted Plan inbox.** New ideas go in at the top; open ideas are listed newest first by day, with who wrote them, their repos and the first line of their notes, and filters for All, From agents and Mine. The selected idea has **File in…**, **Start task** and **Drop**, also from the keyboard (F, S, D, J/K), and projects that already work in the idea's repos are offered first. Dropped ideas fold away and can be restored. See [Plan](https://jakubprill.github.io/trackwall/features/plan).
- **Project progress at a glance.** A project shows "x of n done" with a bar, how many tasks wait for you and a **Hide done** toggle; each item shows its repos and what its task is doing now, in the same words as Sessions. A selected item opens for reading first, with **Edit** for its fields. See [Plan](https://jakubprill.github.io/trackwall/features/plan).
- **A board for each project.** **Outline | Board** in the project header shows the items that are not split further as cards in Idea, Ready, In progress, In review and Done. Drag a card, or press Alt+← / Alt+→, to move it. See [Plan](https://jakubprill.github.io/trackwall/features/plan).
- **Board items follow their tasks.** Starting a task on an item moves it to In progress, and once every open task on it reports its result, to In review; the task's row in Sessions says "In review". Your review or a "Fix" puts it back to In progress. Done and Dropped stay yours. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Workspace knowledge you can review.** Entries are split into "Needs your approval" and "Approved", with a search and filters by kind and repo; the selected entry opens in the right column with **Approve this version**, one at a time. The left column shows how many entries wait for approval. See [Workspace knowledge](https://jakubprill.github.io/trackwall/features/knowledge).
- **Usage in its own Settings category.** "Settings > Usage" shows Copilot usage across the view's width, with the week's totals as tiles, and MCP calls as a table you can filter by tool and agent. "Agents" keeps only settings, with the Copilot CLI tool list folded. See [Copilot usage](https://jakubprill.github.io/trackwall/features/copilot-usage) and [MCP calls](https://jakubprill.github.io/trackwall/features/mcp-calls).
- **Keep the screen on.** "Settings > App" can keep the screen from turning off while agents work, or always while Trackwall runs. It is off by default. See [Keep the screen on](https://jakubprill.github.io/trackwall/features/keep-screen-on).

## Fixed

- **A model that only speaks the Responses API works through a gateway.** When the gateway refuses Chat Completions saying the model "only supports the Responses API", Trackwall now takes that as the model's format instead of failing at the first turn. The Model fields suggest `auto` first. See [mise environment](https://jakubprill.github.io/trackwall/features/mise-environment).

## Moving from 0.5.22

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.23, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. If you skipped 0.5.20 and run Trackwall in a dev container, read its "Before you start".

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
