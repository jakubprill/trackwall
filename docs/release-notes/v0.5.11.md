Trackwall 0.5.11 adds the Plan view for ideas and projects, keeps everything it puts in the projects folder in one `.trackwall` folder, installs Java navigation with one button, lets the desktop app work with a daemon in a dev container and pushes the local config store only to the address you chose.

## Before you start: two one-time steps

- **Choose where the local config store pushes.** If your local config store had a remote, Trackwall stops pushing it until you confirm the address once: open "Settings > Workspace" and press "Push to this remote" under the local config store. Your backups stay on this computer until then.
- **Hidden folders move into `.trackwall`.** At its first start, Trackwall moves `.trackwall-local`, `.trackwall-worktrees`, `.trackwall-lsp`, `.trackwall-scratch` and `.trackwall-removed` in your projects folder into one folder, `.trackwall`. Nothing for you to do, unless your antivirus or backup rules name the old folders: point them at `.trackwall`. Running task worktrees stay where they are. A folder that cannot be moved, for example because Windows holds a file in it, is moved at the next start.

## Fixed

- **Pushes stay where you approved them.** The local config store is pushed only to the address you chose, even if something changes its `origin`, and "Stop pushing" keeps backups on this computer. Before a task branch is pushed, three tricky forms of push address that pointed to another host than the one shown are now refused.
- **More survives a restart.** A task's last verification stays in its panel, an agent turned away by an untrusted mise config hears when you trust it after a restart, and a repo removal whose folder is already gone is dropped instead of coming back.
- **Java navigation on macOS.** Installing Java for Java navigation no longer lets mise configs above the install folder take part.

## What's new

- **Plan.** A new view (Ctrl+5) holds an inbox of ideas and your business projects split into items. Alt+N writes an idea into the inbox from any view, even from a session terminal. "Start task" on an item opens the task form with its repo and a prompt made of the item, and agents can read and update items too. See [Plan](https://jakubprill.github.io/trackwall/features/plan).
- **Java navigation with one button.** "Settings > Agents > Java navigation" has an Install button that downloads jdtls, installs its Java with mise and sets everything up. While a task runs, its header shows how jdtls is doing, from "Java importing" to "Java ready" or "Java import failed", and a repo with both Maven and Gradle builds is imported with Maven. See [Java navigation](https://jakubprill.github.io/trackwall/features/java-navigation).
- **Simpler supervisor panel.** The header shows only the supervisor's name, its state and Stop. While no supervisor runs, a card offers "Start my day", "Continue" and "New conversation", each with a sentence on what it does. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).
- **More on a task's grid tile.** A "Trust mise" chip stays until you trust the mise config the agent changed, a chip shows a running, passed or failed verification, and the ⋯ menu has the branch, port, model, VS Code, Verify, Stop or Resume and Changes without opening the task alone. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions).
- **Frontends connect to their BFFs in the graph.** OpenAPI specs a repo keeps or generates a client from, and `openapi-typescript` scripts in `package.json`, become HTTP clients on the repo card, so the graph connects a frontend to the BFFs it calls. See [Graph](https://jakubprill.github.io/trackwall/features/graph).
- **The desktop app with a daemon in a dev container.** "Settings > App > Daemon in a container" takes the address the container's daemon opens with. The app then connects to that daemon instead of starting its own, so the tray, notifications, windows and links work with it. "Open in VS Code" opens VS Code attached to the container, also from the page in the browser, and with "Projects folder on this computer" set, "Show in Explorer" works again. On Linux the doctor warns when the projects folder is a folder of the host mounted into the container, which makes git slow. See [Run in a dev container](https://jakubprill.github.io/trackwall/guide/dev-container).

## Moving from 0.5.10

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.11, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. Then take the two steps at the top of this note.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
