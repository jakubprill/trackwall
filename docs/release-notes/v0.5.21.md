Trackwall 0.5.21 shows how ready each repo is for agents, lets you move a session, a task or the supervisor to another model without losing the conversation, makes the supervisor use fewer tokens, and marks a passed Verify outdated once the code changes.

## What's new

- **Agent readiness.** With no repo selected, the connection graph's panel starts with how many of your repos agents can build, test and run, such as "4 of 6 ready", and lists each gap once with the repos it is in: no build or test task, an untrusted mise config, a Spring Boot app without a `dev` task, a tool version outside the mise config, HTTP calls without a target. Each gap has one fix, such as "Add convention tasks" for every Maven, Gradle and npm repo at once, or "Ask an agent…". See [Connection graph](https://jakubprill.github.io/trackwall/features/graph).
- **Restart on another model.** **Model** in a session's header, or the robot button in a task's header or the supervisor panel, restarts it on the model you pick with the same conversation, in the API format that model answers in; a stopped task resumes on it with "Resume on this model". The task keeps the new model from then on. This is the way to change the model with your own model provider, where `/model` offers only the model the session started on. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions) and [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **A warning for a model your provider does not offer.** The Model fields still take any id, but an id your provider does not list gets a yellow "The provider does not offer it", with the closest model it does offer as a link that takes it. See [mise environment](https://jakubprill.github.io/trackwall/features/mise-environment).
- **A supervisor that costs less.** A task's report wakes the supervisor once instead of twice and already says what the task changed, and `get_session` answers agents with short text instead of JSON, so the supervisor makes fewer and smaller model calls. "Copilot usage" moved up in "Settings > Agents", above "MCP calls". See [Copilot usage](https://jakubprill.github.io/trackwall/features/copilot-usage).
- **A passed Verify goes outdated when the code changes.** Within about 15 seconds of an edit to a task's files, its passed verification shows "passed · outdated" instead of green, with a line to verify again, and the Sessions row, the supervisor and the merge request draft say so too. Commits and ignored build output do not count. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).

## Fixed

- **The window's background effect looks right at once**, on the window's first show and under session terminals.

## Moving from 0.5.20

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.21, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. If you skipped 0.5.20 and run Trackwall in a dev container, read its "Before you start".

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
