Trackwall 0.5.10 keeps what was waiting for you and your agents across a restart, tells a running session when its mise environment changed, gives agent tasks Java navigation and puts the New session options into one row.

## Fixed

- **Nothing waiting is lost on restart.** A restart or an update used to bring the sessions back but drop what was waiting in Trackwall: task proposals you had not started or rejected, review comments and messages a task's agent had not read, and the updates the supervisor and main session had not read. All of it comes back now, and a resumed session is asked to read what it missed. Settings › Files lists the new file, `agent-queues.json`.
- **Ending a task on Windows.** Removing a task's worktree, and git's temporary folders, now retries while Windows still holds a file for a moment after git, a build or an antivirus scan, instead of failing and leaving the folder behind.
- **Security updates.** The updater's zip library and KaTeX, used in the README view, are updated past their security advisories. An update package that contains a symbolic link is refused.

## What's new

- **Restart a session to apply a new mise environment.** While a running session's panel is open, Trackwall checks whether mise would now give the session a different environment, for example after you add a token to `mise.toml` or a name to `agentSecrets`. If it would, a strip under the header names what changed, never the values, and "Restart to apply" restarts the session with the same conversation. See [mise environment](https://jakubprill.github.io/trackwall/features/mise-environment).
- **Options as pills on the New session form.** Under the prompt one row of pills shows each option and changes it with a click: "Own worktree", "No approvals" and "Model". A task typed on the form can now run on a chosen model, and the form remembers the worktree and model per repo. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions) and [Tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Java navigation for agent tasks.** After you unpack Eclipse JDT Language Server once and name its paths in `workspace.yaml`, a task in a Java repo can turn on the "Java navigation" pill. Its agent then finds definitions, references, implementations and calls instead of searching text. See [Java navigation](https://jakubprill.github.io/trackwall/features/java-navigation).
- **Running in a dev container.** A new guide shows how to run Trackwall's daemon in a Linux dev container with the page in your browser. In such a setup links now open in a new browser tab, and the buttons that need a desktop say why they cannot work instead of doing nothing. See [Run in a dev container](https://jakubprill.github.io/trackwall/guide/dev-container).

## Moving from 0.5.9

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.10, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
