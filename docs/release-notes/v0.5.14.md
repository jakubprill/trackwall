Trackwall 0.5.14 starts one change across several repos, keeps what agents learn about your repos as workspace knowledge you approve, saves repeated tasks as routines, commits every turn of a task's agent as a round you can undo, follows each task's merge request and pipeline, and runs in a dev container as an installed Feature that the window can start.

## What's new

- **Changes across several repos.** Start one piece of work in several repos at once: one task per repo, all on one branch name, each agent knowing the other parts and the order their merge requests are to be merged in. See [Changes across several repos](https://jakubprill.github.io/trackwall/features/changes).
- **Workspace knowledge.** Agents propose short facts about your repos, you approve them, and every later session in those repos reads them at the start. See [Workspace knowledge](https://jakubprill.github.io/trackwall/features/knowledge).
- **Routines.** Save a task you repeat, such as updating an API client and checking it compiles, and run it again with one click. Trackwall runs only the exact text you approved. See [Routines](https://jakubprill.github.io/trackwall/features/routines).
- **Rounds.** Every turn of a task's agent that changed something becomes a commit on the task's branch, listed in the new "Rounds" tab; "Undo" takes the last one back. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Merge request and pipeline.** A task's merge request and its pipeline show in the task panel and on each task's row in Sessions, with a notification when a pipeline fails. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **While you were away.** Come back to one line that says which agents finished, which wait for you and which may be stuck. See [While you were away](https://jakubprill.github.io/trackwall/features/while-you-were-away).
- **MCP calls.** See every call agents made to Trackwall's tools, for all agents or for one task. See [MCP calls](https://jakubprill.github.io/trackwall/features/mcp-calls).
- **Agents search more.** New tools: `search_commits` searches the history of all repos at once, `search_task_history` finds tasks you have ended, and `get_app_config` gives a Spring app's configuration with secrets only as "set". A task's agent can ask the session that proposed it a question. See [MCP tools](https://jakubprill.github.io/trackwall/features/mcp).
- **Hand a task to the supervisor.** "Hand to supervisor" in the task panel lets the supervisor follow a task you started yourself, and the supervisor now knows each task's verification and merge request. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).
- **A session without its own worktree** can pick the model, run in Chat (preview) and use Java navigation, like a task. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions).
- **Chat (preview) is easier to read.** Answers are formatted as Markdown, a line above the message box says whose turn it is, and a message written during a turn shows at once as waiting. A Chat task shows its conversation in the task panel.
- **Dev container.** Trackwall installs into a dev container as a Dev Container Feature and keeps its daemon running; `trackwall-container update` replaces it with a newer signed release, and the window can start Trackwall in the dev container you saved. Each release now includes the daemon and its page for Linux. See [Dev container](https://jakubprill.github.io/trackwall/guide/dev-container).
- **Browser tab.** A tab keeps its sign-in until the daemon restarts, and `trackwall-daemon address` prints the page's address. The tab gets the same content security policy as the window.
- **mise tasks.** Convention tasks for the projects folder, and arguments for a task run. See [mise tasks](https://jakubprill.github.io/trackwall/features/mise-tasks).
- **Doctor** checks that sessions can reach GitHub and Copilot through your network and proxy. See [Doctor](https://jakubprill.github.io/trackwall/features/doctor).

## Fixed

- **A handed-over task is not woken for half-done work.** A task that builds on another task's work is asked to look again only when that task's agent commits or you push its branch, not after each round Trackwall commits at the end of a turn.

## Moving from 0.5.13

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.14, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. If you skip 0.5.11, take the two one-time steps from its release note.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
