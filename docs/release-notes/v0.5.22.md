Trackwall 0.5.22 shows groups of related sessions in colour, cleans up the worktrees of old tasks, finds problems in a repo's mise config, and lets you step through tabs from the keyboard.

## What's new

- **Session groups in colour.** A main session and every task under it, at any depth, form a group with its own colour: a stripe on each row in the Sessions list, with ↳1 or ↳2 for how deep a row sits, and a coloured top edge on the grid's tiles that says what they sit under. "⊞ group" on a grouped row shows only that group in the grid, until you clear the chip on the layout bar. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions) and [Main session](https://jakubprill.github.io/trackwall/features/main-session).
- **Old task worktrees.** The "+" (New task) page in Sessions lists the tasks without a running session that have been idle for a while (7 days by default), with the disk each worktree takes. "Remove worktrees" ends them with their branches kept, so every commit stays; a task that would lose uncommitted work is not chosen unless you confirm it. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **mise config problems in agent readiness.** Agent readiness now shows the first problem `mise tasks validate` finds in a repo's mise config, or a field mise does not know, with "Ask an agent…" to fix it, and lists configs `mise fmt` would rewrite, with a **Format** button. See [Connection graph](https://jakubprill.github.io/trackwall/features/graph) and [Repo card](https://jakubprill.github.io/trackwall/features/repo-card).
- **Tabs from the keyboard.** Ctrl+PageDown and Ctrl+PageUp open the next and previous tab of a task or a repo, also while a terminal has the focus (on macOS also ⌘⇧] and ⌘⇧[). A Shell tab now starts its shell only when you press "Open a shell" (or Enter), so passing through it starts nothing. See [Navigation and windows](https://jakubprill.github.io/trackwall/features/navigation-and-windows) and [Shell](https://jakubprill.github.io/trackwall/features/shell).

## Moving from 0.5.21

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.22, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. If you skipped 0.5.20 and run Trackwall in a dev container, read its "Before you start".

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
