Trackwall 0.5.5 keeps your sessions across restarts and updates, waits with an update until agents finish their turn, and lets a task run on the model you ask for.

## What's new

- **Sessions come back after a restart.** When Trackwall quits, restarts or updates, the next start opens again every session that was running, the supervisor and task sessions included, with the same conversation. An agent that was in the middle of a turn waits for you in the reopened session: ask it to go on. Sessions you stopped yourself stay stopped. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions).
- **Update after their turn.** While an agent is working or waiting for your approval, the update strip says how many and offers "Update after their turn", which installs as soon as the last one ends, or "Update now". See [Updates](https://jakubprill.github.io/trackwall/features/updates).
- **Resume the supervisor.** Once you have talked to a supervisor, its panel shows "Resume", which goes on with the last conversation, also after you closed it or Trackwall restarted, and "New" for a clean one. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).
- **A model for a task.** Ask the supervisor for a model, as in "review this on Opus", and it names it on the proposal. You see it in a field under the prompt and can change or clear it before you start the task. The task keeps its model when it is resumed, and its panel shows it next to the task port. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).

## Moving from 0.5.4

Click "Update and restart" when Trackwall offers 0.5.5, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays. This update still ends the sessions that run in 0.5.4, because 0.5.4 does not record them; from 0.5.5 on, sessions come back after each update.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
