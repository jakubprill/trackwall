Trackwall 0.5.7 shows every file Trackwall reads or writes in Settings, lets you talk to the supervisor in a conversation view instead of a terminal, and makes the mouse work in every session window.

## Fixed

- **Mouse in a session window.** A window opened after its session had started did not scroll, click or select (and so copy) in Copilot CLI. It does now.

## What's new

- **Config files.** "Settings > Files" lists every file and folder Trackwall reads or writes, grouped by where it lies, with what it is for, whether it is there and a link to its page. Every key of `workspace.yaml` shows its value and where to change it, and a key Trackwall cannot read or does not know, such as a misspelled one, is named with its line, also in the doctor. "Local config in repos" shows which repos have `mise.local.toml` or `.worktreeinclude` and whether each is backed up. See [Config files](https://jakubprill.github.io/trackwall/features/config-files).
- **Conversation view for the supervisor (preview).** Press the speech-bubbles button next to the start buttons before you start the supervisor, and it opens as a conversation: messages you can scroll, select and copy, each command or file change as a line you can open, and its approval requests with buttons right below. Trackwall remembers your choice, also for "Start my day", and "Resume" goes on with the same conversation in either view. For now only the supervisor has it, and answers show as plain text. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).

## Moving from 0.5.6

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.7, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
