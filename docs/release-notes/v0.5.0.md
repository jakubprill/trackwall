Trackwall 0.5.0 makes the app responsive on Windows machines where every program start is slow, takes a finished task to a merge request, and keeps the supervisor to coordinating.

## Fixed

- **Slow views on Windows.** On a machine that scans every program start, the repo list, tags and graph could stay on "Loading" with twenty repos or more, because each refresh started several git processes per repo. Trackwall now starts far fewer of them and never too many at once, so the views answer again.
- **Small screens.** On a 1280-pixel window a task's approval stays answerable: the sections above the task terminal take at most a third of the panel, and the approval's buttons show in the tray panel even when the terminal cuts the top of the dialog. Home keeps its 3D view readable with the supervisor panel pinned.
- **Messages to a task.** A task's agent now follows what the session that proposed it writes, also when it changes the task's prompt; only what you type into the task's session or send as a review ranks above it.

## What's new

- **Merge request from a task.** A finished task's panel has a "Merge request" section: push the task branch, open your repo host's own merge request form with the title and the agent's summary filled in, and follow the merge request and its pipeline from Trackwall. See [Tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **The supervisor coordinates, it does not change code.** The supervisor can no longer run shell commands or write files; it reads your repos and hands every change to a task you approve and review. To let it work itself, set `supervisor.changesCode: true` in `workspace.yaml`. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).

## Moving from 0.4.1

Click "Update and restart" when Trackwall offers 0.5.0, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). From 0.4.0 install by hand, as described in the 0.4.1 note. Your data in `~/.trackwall` stays. A supervisor that is running keeps its old rights until you start a new one.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
