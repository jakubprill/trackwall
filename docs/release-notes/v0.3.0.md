Trackwall now does more than browse repos: it runs Copilot CLI sessions and agent tasks next to them, and gives the agents an MCP server with your whole projects folder. The interface is in English.

## What's new

- **Projects folder.** Repos come from one folder you set in "Settings" instead of a hand-kept list. Clone from GitLab or GitHub, sync all repos and run a batch command (sync, `mise install`, setup, build) on many of them at once.
- **Repo details.** mise tasks with live logs, a repo card read from the build files (packages, Spring Boot apps, endpoints, DTOs), tags, uncommitted changes and a Markdown README with Mermaid diagrams.
- **Connection graph.** The "Overview" view draws which repos use whose packages and call whose endpoints.
- **Sessions.** Several Copilot CLI sessions in terminals owned by the daemon, so they keep running when the window is closed. Each shows whether it is working or waiting for you; Alt+1…9 and Alt+J switch between them and a grid shows several at once. Agent tasks run in their own worktree and branch.
- **MCP server for Copilot CLI.** Agents can list and read repos, search code across all of them, query the graph, read logs and errors, run mise tasks, start services with their dependencies and call their endpoints, and propose tasks to other sessions. The "Daemon" view shows the command that connects it.
- **Home.** A 3D dashboard of the daemon, sessions and repos.
- **Desktop.** Several windows, system notifications and a tray panel when a session waits for you, `trackwall://` links, a folder picker, Show in Explorer/Finder and drag and drop.

The full description is in [features.md](https://github.com/jakubprill/trackwall/blob/v0.3.0/docs/features.md).

## Moving from 0.2.0

Close Trackwall from the tray (Quit) and replace the folder or `Trackwall.app` with the new one ([installation](https://github.com/jakubprill/trackwall/blob/main/docs/release.md#installing-on-a-new-computer)). The repo list from 0.2.0 is not read any more: after the first start, set the projects folder in "Settings". To use the MCP server, run the command from the "Daemon" view once.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- No automatic updates yet.
- macOS on Apple Silicon only.
