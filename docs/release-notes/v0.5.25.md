Trackwall 0.5.25 adds a light theme, compares models over your own tasks, retries a failed task on a stronger model, checks a task's changes against the repo's own rules, tells you when two tasks would conflict on merge, and shows Copilot usage week by week.

## What's new

- **A light theme.** In "Settings > App > Theme", "Light" turns every window light, and "Same as the system" follows Windows or macOS, also when the system switches during the day. Session terminals and the 3D scene on Home stay dark. See [Navigation and windows](https://jakubprill.github.io/trackwall/features/navigation-and-windows).
- **Model statistics.** "Models" in "Settings > Usage" groups your ended tasks by the model that did the work: how often they passed verification, what one task cost and what one verified task cost, with a sentence naming the model that passes most often and the cheapest one per verified task. See [Model statistics](https://jakubprill.github.io/trackwall/features/model-stats).
- **Retry on a stronger model.** When a task's verification fails, its Verify section offers to start the same task again, from the same commit, on a stronger model (set the default in "Settings > Agents"). The first attempt stays, so you can compare the two, and the records remember which task retried which. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Check a task against the repo's rules.** "Check rules" in a task's review asks Copilot CLI whether the changes keep the rules the repo writes down: `AGENTS.md`, `CLAUDE.md`, Copilot instruction files and ADRs, taken as they were when the task started. Every broken rule is quoted and can become a review comment. It can also run on its own when the agent reports. See [Automatic review](https://jakubprill.github.io/trackwall/features/auto-review).
- **Conflicts between tasks.** When two tasks in one repo change the same files, Trackwall now tries merging their commits on the side and says which files would conflict, so you can steer one agent away before the merge. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Copilot usage by week.** "Copilot usage" starts with a bar for each of the last thirteen weeks, with tool definitions set apart, and ranks tasks and sessions with a bar each. Click a bar to open that week. See [Copilot usage](https://jakubprill.github.io/trackwall/features/copilot-usage).

## Fixed

- **Your board edits and an agent's do not overwrite each other.** When an agent writes to a Plan item while you edit it, Save keeps the agent's text in the fields you did not touch, and asks you to choose when you both changed the same field.

## Moving from 0.5.24

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.25, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. Model statistics count only tasks ended in 0.5.24 or later, which recorded their model.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- The VS Code extension is not in the Marketplace: build the `.vsix` from the source.
- A rules check finds only what the rule files say in words; Review still covers bugs.
- The conflict check sees an agent's work once its turn ends and it commits.
