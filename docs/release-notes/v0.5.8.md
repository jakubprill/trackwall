Trackwall 0.5.8 keeps more of its git work inside your projects folder, starts with fewer git calls on Windows, suggests your projects folder on first start and shows where each mise task comes from.

## Fixed

- **Fewer git calls at start on Windows.** When the repo list and the sessions that come back after a restart asked for the repos at the same time, every repo was read twice. Now it is read once, Windows runs at most 4 short git calls at once, and a git call that takes 5 s or more is written to the daemon log with its repo.
- **Git's temporary files stay in the projects folder.** While the "Changes" tab is open, and when local config is backed up, git's temporary files now go to `.trackwall-scratch` in your projects folder instead of the system temp folder. This helps on a computer where only the projects folder is skipped by the antivirus. See [Config files](https://jakubprill.github.io/trackwall/features/config-files).
- **End of the supervisor's answer in the conversation view.** The supervisor could show as waiting for you a moment before the last part of its answer appeared. The answer now always comes first.

## What's new

- **Projects folder suggested on first start.** When your home folder has a `Dev`, `Projects`, `Code` or `source\repos` folder, Settings offers the first one it finds with "Use this folder". See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **Where each mise task comes from.** The "mise tasks" tab labels every task `repo`, `local` or `outside repo`, and the tooltip names the file. The repo list tags repos that have mise tasks only your clone has with `local-mise`. A `mise.toml` that git does not track is now backed up and restored like `mise.local.toml`. See [mise tasks](https://jakubprill.github.io/trackwall/features/mise-tasks) and [Local config](https://jakubprill.github.io/trackwall/features/local-config).

## Moving from 0.5.7

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.8, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
