Trackwall 0.4.1 fixes the blank window of 0.4.0 and brings what was finished since: Start my day, start at sign-in, a waiting badge on the app icon and window zoom.

## Fixed

- **Blank window.** In 0.4.0 the window could show its content for a moment and then go blank, because the window's security policy blocked the 3D view on Home and the live connection to the daemon. Home now draws its 3D view, and sessions and changes are live again. If the 3D view fails for another reason, a message takes its place and the rest of the window keeps working. A view that fails shows its error with "Try again" instead of taking the window down.
- **Approvals answered quickly.** A digit or Enter pressed as soon as Copilot CLI draws an approval no longer counts as typed text. Before, a review or a supervisor's message could then wait for your next message.
- **Keys typed while a session terminal connects** are no longer lost.
- **Windows: session titles.** A session no longer takes the path of the Copilot CLI program as its title.
- **Stopping a service.** A service is reported stopped only once its port is free. A Gradle app that keeps the port after its task ends now shows as stopping, with the reason, instead of stopped.

## What's new

- **Start my day.** One button in the supervisor panel syncs every repo and starts the supervisor with a briefing of what changed since your last day start and what waits for you. Your own morning instructions go into `dayStart.prompt` in `workspace.yaml`. See [Start my day](https://jakubprill.github.io/trackwall/features/start-my-day).
- **Start at sign-in.** "Settings" can start Trackwall when you sign in, with only the tray icon on screen.
- **Waiting badge.** The number of sessions and task proposals waiting for you shows on the app icon: in the Dock on macOS and on the taskbar button on Windows. A dot on the tray icon shows it too.
- **Window zoom.** Ctrl+= / Ctrl+- / Ctrl+0 (⌘ on macOS) zoom each window separately and remember the level.
- **The supervisor talks to sessions.** A main session or the supervisor can send a message to a task's session and wakes up when its tasks change.
- **New sessions.** A new session's state and input box are read from its screen before Copilot CLI reports anything, so it no longer looks stuck at the start.

## Moving from 0.4.0

0.4.0 checks for updates by itself, but its window may be blank, so the "Update and restart" strip may not show. If it does not, quit Trackwall from the tray ("Quit") and install 0.4.1 by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
