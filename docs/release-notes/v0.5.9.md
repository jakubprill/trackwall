Trackwall 0.5.9 shows your repos at once instead of waiting for git to read all of them, lets you choose which git Trackwall runs for its local git calls, keeps a session's screen while its terminal connects and brings a repo's local config back when you clone it again.

## Fixed

- **No black terminal when you come back to a session.** Coming back to "Sessions", or switching sessions or layouts, shows the session's last screen at once instead of a black terminal. "Connecting to the session…" shows in the corner while the live screen is late. The daemon log also notes every moment the daemon stood still for half a second or more, which helps find the cause on a slow machine.
- **Doctor and the Copilot CLI config file.** The doctor no longer warns that Copilot CLI does not trust your projects folder when it does, and Settings › Files no longer shows Copilot CLI's `config.json` as broken. Copilot CLI writes comment lines at the top of that file, and Trackwall now reads past them.

## What's new

- **Repo list at once.** "Repos" and "Home" show every repo right away, marked "loading", and their statuses arrive in batches. In "Repos" the selected repo and the top of the list come first. A repo that is still loading is drawn faint in "Home" and stays out of "Needs you". If a batch fails, "Repos" shows the error with "Retry". See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **Git program.** If starting git is slow on your machine because security software checks every program start, point "Git program" in "Settings > Workspace" at another git, for example MinGit unpacked into a folder your antivirus skips. Trackwall then reads your repos with that git, while fetch, push and clone keep using git from `PATH`. Saving checks that the program answers like git. If it stops answering, Trackwall falls back to git from `PATH` and the doctor warns. See [Repos](https://jakubprill.github.io/trackwall/features/repos) and [Doctor](https://jakubprill.github.io/trackwall/features/doctor).

- **Local config comes back on clone.** When you clone a repo again with the "+" button, the `mise.local.toml` and untracked `mise.toml` that Trackwall kept for that folder go back into the new clone by themselves. See [Local config](https://jakubprill.github.io/trackwall/features/local-config).
- **What each link in the graph means.** "Overview" says whether a link is a runtime call ("calls · HTTP") or a build dependency ("depends on · package"), and a manual link in `workspace.yaml` can say `kind: depends-on`. Starting a service with its dependencies follows only calls. A Spring web app with no endpoint found gets "no endpoints" on its card, and HTTP clients whose target Trackwall cannot find are listed as graph problems. See [Graph](https://jakubprill.github.io/trackwall/features/graph).
- **mise variables on every session tile.** In the 2, 4 and Auto layouts too, a session that got variables from mise shows a key badge with their number next to its title, yellow when it got less than its place gives. Hover the badge, or click to pin it, to see the names in groups: secrets the agent's tools get, secrets hidden from them, and the other variables. See [mise environment](https://jakubprill.github.io/trackwall/features/mise-environment).
- **Documentation.** New guide pages explain [where agents work](https://jakubprill.github.io/trackwall/guide/where-agents-work) and [every environment variable](https://jakubprill.github.io/trackwall/guide/environment-variables) Trackwall reads.

## Moving from 0.5.8

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.9, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
