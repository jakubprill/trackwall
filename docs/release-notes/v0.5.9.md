Trackwall 0.5.9 shows your repos at once instead of waiting for git to read all of them, and lets you choose which git Trackwall runs for its local git calls.

## What's new

- **Repo list at once.** "Repos" and "Home" show every repo right away, marked "loading", and their statuses arrive in batches. In "Repos" the selected repo and the top of the list come first. A repo that is still loading is drawn faint in "Home" and stays out of "Needs you". If a batch fails, "Repos" shows the error with "Retry". See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **Git program.** If starting git is slow on your machine because security software checks every program start, point "Git program" in "Settings > Workspace" at another git, for example MinGit unpacked into a folder your antivirus skips. Trackwall then reads your repos with that git, while fetch, push and clone keep using git from `PATH`. Saving checks that the program answers like git. If it stops answering, Trackwall falls back to git from `PATH` and the doctor warns. See [Repos](https://jakubprill.github.io/trackwall/features/repos) and [Doctor](https://jakubprill.github.io/trackwall/features/doctor).

## Moving from 0.5.8

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.9, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
