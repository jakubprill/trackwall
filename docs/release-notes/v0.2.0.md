Pierwsze wydanie pod nazwą **Trackwall**. Wersja 0.1.0 wyszła jeszcze jako Pitwall (zmiana nazwy: ADR-12).

## Nowości

- **Przeglądanie repo.** Zakładka „Repo”: dodajesz lokalny katalog z gitem (pełną ścieżką), a Trackwall pokazuje gałąź, liczbę zmian i ahead/behind, README, drzewo plików z podglądem i ostatnie commity, a jednym przyciskiem otwiera repo w VS Code. Lista repo jest w `~/.trackwall/workspace.yaml`. Wymaga `git` w `PATH`.
- **Nowy wygląd.** Ciemny interfejs w stylu HUD z jednym akcentem kolorystycznym, spójny w całej aplikacji.
- **Półprzezroczyste okno.** Mica (Windows 11) lub Acrylic (Windows 10) na Windowsie, vibrancy na macOS. Bez efektu systemowego, albo przy włączonym „zmniejsz przezroczystość”, okno zostaje nieprzezroczyste.
- **Daemon działa też pod samym Node** przy uruchomieniu ze źródeł (README), nie tylko jako skompilowana binarka Bun.

## Przejście z Pitwall 0.1.0

Trackwall nie wykrywa ani nie przejmuje starej instalacji: ma inny folder, katalog stanu i identyfikator aplikacji. Ze starej wersji nic nie jest potrzebne.

1. Zamknij Pitwall z traya (Wyjdź), żeby zatrzymać też jego daemona.
2. Usuń starą aplikację: na Windowsie folder `%LOCALAPPDATA%\Programs\Pitwall`, na macOS `Pitwall.app` z Aplikacji.
3. Opcjonalnie usuń stary stan `~/.pitwall` (na Windowsie `%USERPROFILE%\.pitwall`) i dane okna zapisane pod starym identyfikatorem: na Windowsie `%LOCALAPPDATA%\dev.pitwall.desktop`, na macOS `~/Library/WebKit/dev.pitwall.desktop` i `~/Library/Caches/dev.pitwall.desktop`.
4. Zainstaluj Trackwall według [instrukcji](https://github.com/jakubprill/trackwall/blob/main/docs/release.md#instalacja-na-nowym-komputerze). Na Windowsie aplikacja trafia teraz do `%LOCALAPPDATA%\Programs\Trackwall`, a stan do `%USERPROFILE%\.trackwall`.

Na Windowsie w PowerShellu kroki 2 i 3:

```powershell
foreach ($p in "$env:LOCALAPPDATA\Programs\Pitwall", "$env:USERPROFILE\.pitwall", "$env:LOCALAPPDATA\dev.pitwall.desktop") {
  if (Test-Path $p) { Remove-Item $p -Recurse -Force }
}
```

## Znane ograniczenia

- Aplikacja nie jest podpisana: na Windowsie SmartScreen blokuje plik pobrany przeglądarką (pobierz przez `gh` albo `curl.exe` lub użyj `Unblock-File`), na macOS trzeba zdjąć kwarantannę (`xattr`). Szczegóły w instrukcji instalacji.
- Brak automatycznych aktualizacji; aktualizacja to podmiana folderu lub `.app`.
- macOS tylko Apple Silicon.
