Trackwall 0.5.3 makes messages between the supervisor and its tasks arrive reliably, whether the other session is busy or idle.

## Fixed

- **Messages reach a busy session.** When the supervisor sends a task a message, or a task reports back while the supervisor is in the middle of a turn, the line used to wait until that session stopped. It now reaches the agent right away, with the result of the next tool it runs, and again at the start of a new turn when the current one ends. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).
- **Messages reach an idle session.** Trackwall used to type the line into an idle session's terminal as soon as its agent stopped, sometimes before the input box was back on the screen, and the line got lost. It now types it once the input box really shows, never into text you are writing, and tries again a few seconds later if the line did not go through.

## Moving from 0.5.2

Click "Update and restart" when Trackwall offers 0.5.3, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays. Sessions running when you restart end with it.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
