Trackwall 0.5.20 proposes tasks to the repos a change reaches, shows the versions repos disagree on, reports what Copilot used each week, and lets the supervisor and sessions run on models of your provider.

## Before you start

If Trackwall runs in a dev container, give the container a git sign-in of its own: Trackwall there does not get your computer's SSH keys or git sign-in, also not while VS Code is open. The doctor's new "Git access to repo hosts" line says whether git reaches each host. See [Git and SSH](https://jakubprill.github.io/trackwall/guide/dev-container#git-and-ssh).

## What's new

- **Tasks proposed to the repos a change reaches.** When a task's agent finishes a turn, Trackwall proposes a task to each repo that calls an endpoint the task's commits changed, and, for a shared Java library, to each repo that imports a public class the commits removed or changed. The proposals wait in "Sessions" under the task, marked "Proposed by Trackwall"; nothing starts until you approve it. See [Impact of a task](https://jakubprill.github.io/trackwall/features/impact).
- **Version drift.** The connection graph's panel lists the versions your repos disagree on: Java, Node.js and the other mise tools, Spring Boot, parent poms and BOMs, and build plugins. "Align to …" starts one change that brings the older repos up to the newest. See [Connection graph](https://jakubprill.github.io/trackwall/features/graph).
- **Copilot usage.** A weekly report of what Copilot CLI used, by task, by session and by tool, compared with the week before. See [Copilot usage](https://jakubprill.github.io/trackwall/features/copilot-usage).
- **A failed pipeline job at the merge request.** A task's merge request shows the end of a failed job's log, and "Fix" hands the logs of the failed jobs to the task's agent. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Models of your own provider.** The Model fields of a new session, a task proposal and the supervisor suggest the models your provider offers as you type, and Trackwall starts each session in the API format its model answers in, so you no longer pick between Responses and Chat Completions. See [mise environment](https://jakubprill.github.io/trackwall/features/mise-environment).
- **The supervisor on a model of its own.** "Settings > Agents > Supervisor model" runs the supervisor on another model than Copilot CLI's default, such as a cheaper one. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).
- **Git access to repo hosts in the doctor.** A new line checks that git reaches every repo host the way a sync does, and names the reason when it does not. See [Doctor](https://jakubprill.github.io/trackwall/features/doctor).
- **Find in a terminal.** Ctrl+Shift+F (Cmd+F on macOS) finds text on a terminal's screen and in what scrolled away, and Ctrl+click (Cmd+click) opens a web address it printed. See [Sessions](https://jakubprill.github.io/trackwall/features/sessions).
- **Clickable `trackwall://` links** in conversations and browser tabs, also as bare text or in backticks. See [Links](https://jakubprill.github.io/trackwall/features/links).
- **A better GitLab search when cloning.** "+" in "Repos" pages through the results, searches all projects you can see, and filters by topic and language. See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **`/model` in Chat.** `/model` with a model id, such as `/model gpt-5-mini`, switches the model of a conversation until its next start. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).

## Moving from 0.5.19

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.20, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. In a dev container, read "Before you start" above.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
