Trackwall 0.5.1 makes agent tasks fast on machines where an antivirus scans your profile, and brings the smaller fixes finished since 0.5.0.

## Fixed

- **Slow tasks.** Task worktrees used to live in `~/.trackwall/worktrees`, under your profile, which an antivirus scans on every file access. New tasks now get their worktree in `.trackwall-worktrees` inside your projects folder, on the same disk as your repos and under the same antivirus exclusion. The Repos list does not show that folder. To put worktrees elsewhere, set "Task worktrees folder" in Settings. See [Tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Paste on Windows.** Ctrl+V pastes into a session's terminal.
- **Repo tags.** A repo keeps its "no mise" tag when only some code files could not be read.

## What's new

- **Update progress.** Installing an update shows each stage, says when a download stalls, and can be cancelled.
- **Card problems by kind.** Each problem on a repo card says what kind it is: a file not read, a file that did not parse, code without a syntax tree, or a list cut short.
- **Which endpoint makes a call.** For Java repos, `find_endpoint` tells an agent which endpoint makes each call, not only which repo: Trackwall follows each endpoint's code to the HTTP clients it uses, so an agent can trace what a change to one endpoint affects. See [Graph](https://jakubprill.github.io/trackwall/features/graph).
- **A more careful supervisor.** Before it hands work to a task, the supervisor works out what the request is about, and sends follow-up work to a running task of the same repo instead of starting a new one. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor).

## Moving from 0.5.0

Click "Update and restart" when Trackwall offers 0.5.1, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays. Tasks you already have keep their worktrees in `~/.trackwall/worktrees` until you end them; only new tasks use the new folder. If Copilot CLI asks to trust each repo or task, add your projects folder to `trustedFolders` in `~/.copilot/config.json`.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
