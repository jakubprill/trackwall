Trackwall 0.5.18 gives every repo and task your own shell, opens a turn's changes beside the conversation view and makes code search answers shorter for agents.

## What's new

- **Shell.** Every repo in "Repos" and every task in "Sessions" has a "Shell" tab: your own shell, already in the repo's folder or the task's worktree, also when Trackwall runs in a container. It keeps running while you look at other views, and "Close" ends it. A task's "Terminal" tab stays the agent's session. See [Shell](https://jakubprill.github.io/trackwall/features/shell).
- **Changes of the turn beside the conversation view (preview).** "Show diff" beside a file change opens it in a panel beside the conversation, with the other files that turn of the agent changed and the picked file's diff with line numbers; ✕ closes it. See [Supervisor](https://jakubprill.github.io/trackwall/features/supervisor) and [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Shorter code search answers.** `search_code` and `search_commits` answer agents with short grep-like lines grouped by repo and file, and `search_code` can list only the files with how many lines match in each, so a search costs the agent less of its context. See [MCP](https://jakubprill.github.io/trackwall/features/mcp).
- **Free disk space in the doctor.** A new row warns when less than 10 GB are free on the disk of your projects folder or your home folder, and says what to clear; in a container it names the disk of Docker's virtual machine. See [Doctor](https://jakubprill.github.io/trackwall/features/doctor).
- **Back up the repos of a dev container.** The dev container guide shows how to copy the `workspace-repos` volume into one file and back, and how to set the container's time zone. See [Dev container](https://jakubprill.github.io/trackwall/guide/dev-container#back-up-the-repos).

## Fixed

- **A task's result is no longer refused for its length.** Task sessions are told the limits of `report_result`, so they keep their summary within them the first time.
- **A stopped daemon shows on Home at once.** When the daemon stops, Trackwall in the middle goes dark with "daemon not responding" right away, and the sessions and tasks that stopped with it leave the picture; everything comes back within seconds of reconnecting. See [Home](https://jakubprill.github.io/trackwall/features/home).

## Moving from 0.5.17

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.18, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. If you skipped 0.5.17 and run Trackwall in a dev container, read its "Before you start".

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- Chat (preview) has no Java navigation for tasks, and a running task cannot switch between the terminal and Chat.
