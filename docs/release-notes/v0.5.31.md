Trackwall 0.5.31 opens Repos on the state of every repo against the server and checks the servers for new commits every 15 minutes without fetching, warns in the New task form when main is behind, explains features where you meet them and lists what is new after an update, takes Home off the view bar, keeps Plan and knowledge in the workspace store if you want, and deletes a word on Ctrl+Backspace in session terminals.

## What's new

- **All repos.** "Repos" opens on "All repos": one line that sums the repos up, such as "3 to pull · 2 changed", and a row for each repo that needs a look (uncommitted files, commits to pull, a diverged branch, work only in this container, a repo git cannot read), each with its next step such as "Pull 15", "Changes" or "Shell". The clean repos fold into one line. A row of the repo list no longer says "clean" for a repo that is behind. See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **New on the server.** Every 15 minutes Trackwall asks each repo's server whether the branch it tracks has moved, with your own sign-in and without fetching anything, and such a repo reads "new on the server" with "Pull". When a server does not answer, for example with the VPN off, All repos says so calmly. "Settings > Repo hosts > Check for new commits" turns it off. See [Repos](https://jakubprill.github.io/trackwall/features/repos).
- **Sync main in the New task form.** When a repo's `main` lacks commits the server has, the form says so above "Create task" and offers "Sync main", so the task starts from the newest code. See [Agent tasks](https://jakubprill.github.io/trackwall/features/tasks).
- **Tips and What's new.** The first time you meet a feature such as "Own worktree", "Next waiting", a task's evidence, "Ready to close", "Plan first", "Verify" or "Always allow", a short tip under it says what it does, with a link to its page. After an update, a strip above the views lists the changes worth a look, each with "Show". "Settings > App > Tips and What's new" turns both off or shows the tips again. See [Tips and What's new](https://jakubprill.github.io/trackwall/features/tips).
- **Home off the view bar.** Home has no icon on the view bar until you show it in "Settings > App > Home"; Ctrl+6, the command palette and the macOS menu open it either way. The container's health warnings are counted on the Settings icon instead, and the top of the Sessions list shows the tasks ready to close with "Close all". See [Home](https://jakubprill.github.io/trackwall/features/home).
- **Plan and knowledge in the workspace store.** The local config store is now the workspace store, and "Keep Plan and knowledge in the store" (off by default) gives the approved knowledge and routines, the board and your task templates a history in git that goes with the store's pushes. A proposal never goes in. See [Local config backup](https://jakubprill.github.io/trackwall/features/local-config).
- **Ctrl+Backspace deletes a word** in a session's terminal, as in any text field on Windows, instead of one character.

## Fixed

- **A refusal of git says what changed.** When a package install in a sandboxed task rewrote the repo's shared git hooks, every git call of Trackwall in the repo was refused without saying what changed. The refusal now names the changed places and the sandboxed tasks, and "End task" can accept a changed hook so git runs again; a changed `.git/config` key still has to be undone in the repo.
- **The Add repo search stays in place while a new search runs**, instead of emptying the results and moving the search box and filters on every keystroke.

## Moving from 0.5.30

Click "Update and restart" (or "Update after their turn" while agents work) when Trackwall offers 0.5.31, or install it by hand ([Update by hand](https://jakubprill.github.io/trackwall/guide/install#update)). Your data in `~/.trackwall` stays, and the sessions that were running come back after the restart. The workspace store moves each repo's local config into `repos/` with one commit of its own. Home's icon is hidden until you show it again. Download `trackwall-0.5.31.vsix` from the release to update the VS Code extension.

## Known limitations

- Sessions run Copilot CLI only, and it has to be installed and signed in.
- The app is not signed: on Windows download it with `gh` or `curl.exe`, or run `Unblock-File` on the zip; on macOS remove the quarantine with `xattr`.
- A proxy that signs you in with your Windows account or replaces certificates can stop the update download; the manual update still works then.
- macOS on Apple Silicon only.
- The VS Code extension is not in the Marketplace: download its `.vsix` from the release and install it by hand after each update.
- "Pull" only fast-forwards: a branch that has diverged from the one it tracks is left for you to merge or rebase in a shell.
